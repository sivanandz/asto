## 2026-05-23 - Predictable Randomness in Entropy Combiner
**Vulnerability:** The tarot card generator `EntropyRandom` used `math.Random(mixedEntropy)`, which is a predictable pseudorandom number generator, to draw cards. This was technically insecure for a randomizer process meant to represent the "magical" nature of drawing a random card.
**Learning:** Even when incorporating unpredictable external entropy (like accelerometer data), feeding it into a deterministic PRNG with a fixed seed makes the output completely predictable if the seed state is ever known or guessed. This defeats the purpose of gathering sensor entropy in the first place for secure random draws.
**Prevention:** For any security-sensitive or truly unpredictable operation like draws/shuffles, always use a cryptographically secure random source (e.g., `math.Random.secure()`). To preserve the influence of external sensor entropy without compromising cryptographic security, use a hybrid pattern: `(secureRandom.nextInt(max) + entropy.abs()) % max`. Ensure `.abs()` is used to prevent negative modulo results in Dart.
