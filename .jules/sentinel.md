## 2024-05-22 - Fix Predictable PRNG in Sensitive Randomization
**Vulnerability:** The application was using `math.Random(seed)` with predictably generated seeds (time + sensor data) for drawing tarot cards, which could allow a malicious actor to predict the outcome of tarot draws by simulating or guessing the entropy sources.
**Learning:** In Dart, `math.Random(seed)` generates a predictable sequence of numbers for a given seed. Even when combining sensor data and time to create entropy, using it as a seed for a non-secure PRNG makes the randomization predictable. For sensitive operations, secure random generation must be used, even if incorporating additional entropy sources.
**Prevention:** Always use `math.Random.secure()` for sensitive randomization operations. To incorporate additional entropy like sensor data, use a hybrid pattern `(math.Random.secure().nextInt(max) + mixedEntropy.abs()) % max` which ensures cryptographic security while still feeling "physical" or "magical" by incorporating external sensor state, while using `.abs()` to prevent negative modulus issues.
