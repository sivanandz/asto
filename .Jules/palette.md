## 2024-05-23 - IconButton ARIA equivalent
**Learning:** In Flutter, adding the `tooltip` property to `IconButton` widgets is crucial for accessibility. It provides visual text on hover for mouse users and serves as the primary ARIA-equivalent accessibility label (semantically announced as a button with that text) for screen readers like VoiceOver and TalkBack.
**Action:** Always include a clear, descriptive `tooltip` for any icon-only button in the app.
