## 2024-05-24 - Accessibility Labels for IconButtons
**Learning:** In Flutter, adding an explicit `tooltip` property to `IconButton` widgets provides an ARIA-equivalent accessibility label for screen readers as well as a visual hover state, which is crucial for icon-only buttons.
**Action:** Always add `tooltip` properties to icon-only buttons (`IconButton`, `Icon`, etc.) to improve both visual feedback and screen reader accessibility, acting as the Flutter equivalent to ARIA labels.
