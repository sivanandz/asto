## 2026-05-28 - Add Tooltips to Icon-only Buttons
**Learning:** In Flutter, adding a `tooltip` property to an `IconButton` is the standard method for providing both visual hover states for desktop users and ARIA-equivalent accessibility labels for screen readers. This is especially important for icon-only buttons to ensure they are accessible.
**Action:** Always verify that icon-only buttons (like `IconButton`) have a descriptive `tooltip` property set to improve both UX and accessibility.
